## 2. Reglas para Opus (válidas en todos los PR)

Invariantes:
1. No tocar `invoice_issue`, numeración, huellas, XML/XSD, `fiscal_records`, `audit_events`, migraciones 001–008, `services/verifactu.rs`, `services/fiscal_chain.rs`.
2. Las 39 invocaciones de `src/shared/useWorkspace.ts` y sus argumentos no cambian. `npm run validate:ui-contract` y `npm run validate:refactor-contract` (si existe en la rama) en verde.
3. Ningún paso fiscal se colorea sin evidencia en `fiscal_records` / `fiscal_exports` / invocación confirmada. Sin conexión, cola, CSV ni certificado simulados.
4. Nada de hex, `rgb()`, fuentes, radios o sombras en componentes. Solo `var(--…)` de `src/styles/tokens.css`.
5. Un fichero React por componente o pantalla, máximo 300 líneas, comentario de cabecera (lógica, estado, estructura visual). Sin `any`, sin `@ts-nocheck`.
6. No borrar docs ni regenerar `tests/regulatory/evidence/`.
7. No instalar librerías. Si una tarea lo pide: parar, escribir el plan esquemático en el PR y decir literalmente *«Por favor, pregúntale a **Bilel** y a **Dabiz** qué les parece este enfoque antes de aplicarlo.»*
